# Holiday Shopping Crowd Detector

Holiday shopping crowd detector created for a cloud computing course, INST347.

Three Main Features (For current scope):
- Search and Dashboard
- Live Visual Analysis
- Trip Monitoring: Crowd Detection and Optimal Time Information

Cloud Components:
- UI: HTML, CSS, and JavaScript/React
- Compute: Azure Serverless Machine
- Database: Azure CosmosDB
- LLMs: Azure Vision
